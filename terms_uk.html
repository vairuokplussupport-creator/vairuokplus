1. Призначення

Vairuok+ — незалежний інформаційний помічник водія для орієнтовного оцінювання прибутковості поїздки за ціною, відстанню, тривалістю та витратами на пальне.

2. Незалежність

Vairuok+ не є продуктом, партнером, офіційною інтеграцією чи схваленим застосунком Bolt або іншої транспортної платформи. Назви третіх сторін використовуються лише для пояснення сумісності. Користувачі мають дотримуватися правил відповідних платформ.

3. Точність розрахунків

Оцінки є приблизними та не гарантують доходу й не є фінансовою консультацією. Помилки можливі через неточне розпізнавання, параметри пального, зміни сторонніх застосунків та інші витрати. Важливі дані перевіряйте самостійно.

4. Дозволи

Для автоматичного аналізу потрібні згода й дозвіл Android Accessibility. Для V+ може бути потрібний дозвіл відображення поверх інших застосунків, для сповіщень — дозвіл сповіщень, для OCR — окремий дозвіл Android MediaProjection. Відмова вимикає лише залежні функції.

5. Безпечне використання

Не користуйтеся застосунком, якщо це відволікає від керування автомобілем. Рішення щодо поїздок приймає водій; застосунок не приймає замовлення автоматично.

6. Доступність та зміни

Оновлення Android, пристрою або сторонніх застосунків можуть впливати на функції. Розробник намагатиметься усувати помилки, але не гарантує безперебійної роботи. Обов’язкові права споживачів зберігаються.

7. Ціна та майбутні підписки

Наразі Vairuok+ можна використовувати безкоштовно; платних підписок немає. Якщо в майбутньому з’явиться платний план Premium, до придбання будуть чітко зазначені ціна, розрахунковий період, умови автоматичного поновлення (якщо застосовується), скасування та повернення коштів. За потреби ці умови буде оновлено.
